Ключевые формулы
Диэлектрическая проницаемость — формула стенда
ε = C · d / (ε₀ · S)
C — ёмкость (Ф), d — толщина (м), S — площадь (м²), ε₀ = 8.85·10⁻¹² Ф/м. Безразмерная величина.
Закон Кюри–Вейсса — при T > θ_k
ε = A / (T − θ₀) → 1/ε = (1/A)·T − θ₀/A
Линейный участок на графике 1/ε(T): угл. коэф. b = 1/A, своб. член a = −θ₀/A.
МПТ вычисляет b = 1/A и погрешность Δb = Δ(1/A). Затем: A = 1/b, θ₀ = −a/b.

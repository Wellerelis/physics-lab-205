## Что делает калькулятор

Вы вводите результаты измерений (температура и ёмкость образца BaTiO₃(Sr)), калькулятор автоматически:

- **Вычисляет** ε и 1/ε по формуле стенда `ε = C·d/(ε₀·S)` — таблица 2 полностью
- **Находит** температуру Кюри θₖ по максимуму зависимости ε(t)
- **Строит МНК** на линейном участке 1/ε(T) с раскрытыми суммами ΣT, ΣT², D, b, a
- **Считает методом парных точек** — таблица пар bᵢ, ⟨b⟩, σ⟨b⟩, Δb = t·σ⟨b⟩
- **Вычисляет константы** A = 1/⟨b⟩ и θ₀ = −a/⟨b⟩ с погрешностями
- **Генерирует** Python-скрипт `plot_vak.py` для публикационных графиков (A4, ГОСТ 7.32)
- **Формирует протокол** — готовый текст по всем 9 разделам для вставки в отчёт

## Физика

### Диэлектрическая проницаемость

```
ε = C · d / (ε₀ · S)
```

Где C — ёмкость образца (нФ), d — толщина (м), S — площадь обкладок (м²), ε₀ = 8.85·10⁻¹² Ф/м.

### Закон Кюри–Вейсса

При T > θₖ диэлектрическая проницаемость описывается законом:

```
ε = A / (T − θ₀)
```

Линеаризация: `1/ε = (1/A)·T − θ₀/A` — прямая в координатах (T, 1/ε).
Из графика находится угловой коэффициент b = 1/A и свободный член a = −θ₀/A, откуда:

```
A = 1 / b

θ₀ = −a / b
```

### Метод парных точек

```
bᵢ = ((1/ε)_{i+k} − (1/ε)ᵢ) / (T_{i+k} − Tᵢ)     i = 1…k

σ⟨b⟩ = √( Σ(bᵢ − ⟨b⟩)² / (k·(k−1)) )

Δb = t(P = 0.90, f = k−1) · σ⟨b⟩
```

МПТ даёт ⟨b⟩ = 1/A и погрешность Δb. Свободный член a для вычисления θ₀ берётся из МНК.

### Погрешность A

```
δA = δb = Δb / ⟨b⟩
ΔA = δA · A
```

## Как пользоваться

### 1. Параметры

Проверьте значения d, S и ε₀. Коэффициент k = d/(ε₀·S) вычисляется автоматически.

### 2. Табл. 1 — Данные

Введите пары (t, C) для каждого измерения. Шаг 3 °C до максимума ёмкости, затем 1 °C.
Кнопка **«★ Данные 10.04.2026»** загружает встроенные данные эксперимента (41 точка).

### 3. Табл. 2 + График ε(t)

Таблица 2 строится автоматически. Строка с максимумом ε подсвечена — это θₖ.
Интерактивный график с переключением масштаба оси Y (авто / линейный / лог).

### 4. График 1/ε · Кюри–Вейсс

Задайте диапазон строк **выше θₖ**. Доступен выбор режима МПТ:

| Кнопка | Описание |
|--------|----------|
| 1…n | Все точки |
| 2…n | Пропустить первую точку |
| 3…n | Пропустить первые две точки |

При нечётном числе точек средняя автоматически исключается из разбивки.

### 5. Печать графиков

Превью обоих графиков в стиле ВАК + кнопка **«↓ Скачать plot_vak.py»**.
Скрипт содержит ваши данные и готов к запуску:

```bash
cd ~/Downloads
pip install matplotlib
python plot_vak.py
```

Создаёт `Fig1_eps_t.pdf/.png` и `Fig2_inv_eps_T.pdf/.png` в формате A4 альбомный, ГОСТ 7.32.

### 6. Протокол

Кнопка «Скопировать» копирует готовый текст протокола в буфер обмена.

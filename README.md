# Лабораторная работа 2.05

**Температурная зависимость диэлектрической проницаемости сегнетоэлектрика**

Веб-калькулятор для обработки результатов лабораторной работы 2.05 кафедры общей физики СПбПУ Петра Великого. Образец — BaTiO₃ с примесью Sr. Всё работает прямо в браузере, без установки и сервера.

---

## Возможности

- Ввод данных измерений t (°C) и C (нФ) с автоматическим пересчётом
- Вычисление ε и 1/ε по формуле стенда: `ε = C·d/(ε₀·S)`
- Определение температуры Кюри θₖ по максимуму ε(t)
- МНК с раскрытыми промежуточными суммами (ΣT, ΣT², Σ(T·1/ε), D, b, a)
- Метод парных точек — 1/A, погрешность Δb = t·σ⟨b⟩, таблица пар
- Константы A и θ₀ пошагово с подстановкой чисел (МПТ + МНК)
- Интерактивные графики с переключением масштаба
- Полный текстовый протокол — копируется одной кнопкой
- Генерация Python-скрипта `plot_vak.py` для публикационных графиков (A4 альбомный, ГОСТ 7.32)

## Физика задачи

```
ε = C·d / (ε₀·S)

Закон Кюри–Вейсса (T > θₖ):
ε = A/(T − θ₀)  →  1/ε = (1/A)·T − θ₀/A
```

Обработка: МПТ даёт ⟨b⟩ = 1/A и Δb; свободный член a из МНК; θ₀ = −a/⟨b⟩.

**Встроенные данные (10.04.2026):** θₖ = 109 °C, A = (6.74 ± 0.60)·10⁵ K, θ₀ = 354 K.
